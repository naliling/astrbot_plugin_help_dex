# 指令图鉴（help_dex）

把机器人会的一切指令画成一张暗色科幻风的图鉴图片。背景图、Logo、字体颜色全部支持**用指令直接上传和修改**，改完立即生效，不用碰文件、不用重启。

被拉进群时会自动发一条链接，指向一个**只读的浅色网页版图鉴**，并在进群那一刻掐掉 LLM 调用——省得一群机器人刚进群就一起刷屏。

## 两种呈现

| | 怎么触发 | 长什么样 |
| --- | --- | --- |
| **图鉴图片** | `/帮助图鉴`、`指令图鉴`、群里只 @ 它 | 暗色科幻风 PNG，背景/Logo/配色可深度自定义 |
| **网页版图鉴** | 机器人被拉进群时自动发链接 | 浅色卡片网页，顶部可写使用规则，每条指令能一键复制，可按群定制 |

两者共用同一份指令表和 Logo/标题/简介，改一次两边都跟着变。**管理员指令只出现在图片里，永远不上网页**——网页是对公网开放的。

> 私聊机器人发 `/帮助图鉴`，会先给图鉴再给网页地址；群里发就只有图鉴。

## 指令

### 所有人可用

| 指令 | 说明 |
| --- | --- |
| `/帮助图鉴` | 生成指令图鉴图片（发 `指令图鉴` 也可以） |
| 只 @ 机器人 | 群里只 @ 它、不发任何文字，也会直接发图鉴 |
| `/图鉴预览` | 预览当前图鉴效果，并显示自定义状态与识别结果 |
| `/图鉴帮助` | 查看本插件全部用法 |

### 管理员可用

| 指令 | 说明 |
| --- | --- |
| `/图鉴背景` + 图片 | 上传背景图（也支持发图片链接）；发 `/图鉴背景 重置` 恢复默认渐变 |
| `/图鉴logo` + 图片 | 上传 Logo，白底自动抠掉；发 `/图鉴logo 重置` 移除 |
| `/图鉴颜色 <部位> <颜色>` | 自定义**图片**配色，如 `/图鉴颜色 标题 #FF5733` |
| `/图鉴标题` / `/图鉴简介` | 改图鉴上的文字（图片和网页都跟着变） |
| `/图鉴重置` | 颜色、标题、背景、Logo 全部恢复默认 |
| `/图鉴入群 开\|关` | 开关入群欢迎语与进群静默 |
| `/图鉴静默 <秒>` | 进群后多久不响应 LLM，填 `0` 关闭 |
| `/图鉴链接` | 把当前网页地址发出来（会当场探一次通不通）；`/图鉴链接 换` 轮换访问密钥 |
| `/图鉴规则 <文字>` | 改网页顶部的使用规则（换行分条，`重置` 清空） |
| `/图鉴页面 [群号]` | 看某个群的网页专属配置（群里发就默认看当前群） |

可自定义颜色的部位：`背景`（可两个颜色做渐变）、`标题`、`副标题`、`区块`、`指令`、`描述`、`强调`、`卡片`、`边框`、`页脚`。颜色格式 `#RRGGBB`，`卡片` 还支持 8 位带透明度 `#RRGGBBAA`。单独发 `/图鉴颜色` 可查看当前配色。默认是暗色科幻配色。

⚠️ `/图鉴颜色` 只管**图片**的配色，网页是独立的浅色设计，不跟它走。

## 网页版到底有没有用，先说清楚

网页版是**给「群里的人能点开」这件事做的**。它比图片强在三点：

- 手机上看得清。图片在手机上要缩放才能看清字，网页是响应式的
- **每条指令能一键复制**。看到「/天气」，点一下复制，去聊天框直接粘
- 不刷屏。一条链接 vs 一张长图

但**如果没有公网可达的地址，这三条约等于零**——链接发出去，别人点开是错的。

网页服务只监听 `127.0.0.1`，外网根本进不来。所以在配好「对外访问地址」之前：
入群发的是**图鉴图片**（这是自动降级的正常行为，不是坏了），
网页地址只有你自己在这台机器上能打开。发 `/图鉴链接` 会直接告诉你现在属于哪种情况。

## 怎么配

### 临时地址：一条指令

```
/图鉴隧道 开
```

自动拉起、自动填地址、自动自检。地址每次重启都变，群里发过的旧链接会失效。

### 永久地址：三条指令

需要**一个托管在 Cloudflare 的域名**（NS 指向 Cloudflare）。做完地址永久不变，群里那条链接再也不会失效，容器重启也自动恢复。

```
/图鉴隧道 登录
```

返回一个 Cloudflare 授权链接，**在你自己的手机或电脑浏览器里点一下**（容器里没浏览器）。一次性的。

```
/图鉴隧道 固定 help.你的域名.com
```

建隧道、把域名指过来、写好 config、跑起来。以后插件启动会自动恢复它。

## 隧道会自己死掉吗

临时隧道是个独立进程，机器休眠、网络抖动都可能把它带走。现在有守护循环盯着，死了 20 秒内自动拉起。

固定地址更稳：配置写在 `~/.cloudflare/config.yml`，容器重启后插件加载时自动跑起来。

想看状态发 `/图鉴隧道`。

## 入群不触发

发 `/图鉴诊断`（所有人可用），它会告诉你：入群欢迎开关开没开、检测方式是哪个、最近 10 条群事件长什么样、已触发过几个群。

如果它显示「一条群事件都没收到」，说明**框架在插件之前就把事件丢了**，插件根本没机会看见。最常见原因是那个群不在 AstrBot 的会话白名单里——去面板配置里把群号加进去，或把白名单开关关掉。

## 网页上的四个功能

**一键复制指令**——每张指令卡右上角有个「复制」按钮，点一下就把 `/指令` 放进剪贴板。桌面靠鼠标移上去才出现，手机上是常显的（不然点不到）。http 下 clipboard API 不可用时会自动退回老办法。整个过程不发任何网络请求。

**按群定制**——不同群可以有不同的标题、简介和使用规则。在插件配置的「按群定制页面」里一行一条：

```
123456789|群公告版|这个群的使用说明|不要 @ 别人;有事直接发指令;别刷屏
```

字段用 `|` 分，规则用 `;` 分。留空的那一项不覆盖，没配的群走全局的那一份。入群时发的链接自带 `?g=<群号>`，所以每个群看到的确实不一样。发 `/图鉴页面 <群号>` 可以看当前配置。

**私聊发链接**——私聊 `/帮助图鉴` 时，发完图鉴会再附一条网页地址，方便转到需要的地方。群里发不会多发，免得刷屏。

**私聊不给链接的情况**——地址探不通时只发图鉴，不发半截地址。

## 安全上做了什么

- **URL 路径本身就是密钥**（32 位随机 hex），不叫 `help` 也不叫 `dex`
- 路径不对、密钥不对、方法不对，**一律回同一张 404 页面**，不给人试探的反馈
- 密钥比较用 `secrets.compare_digest`，不计时侧信道
- 删掉 `Server` 头，不对外报 Python / aiohttp 版本
- CSP 是 `default-src 'none'`：就算哪天真有 XSS，也**发不出任何外部请求**。页面本身零 fetch、零表单、零外链资源
- 管理员指令一律不上页，且不受「显示管理员指令」配置影响
- 所有动态文本（各插件的 docstring、管理员手填的规则）全量 HTML 转义
- `/图鉴链接 换` 一键轮换密钥，旧链接即刻失效

**要说清楚的边界**：链接发在群里 = 群里所有人可见且随时会被转发。密钥只能防陌生人乱猜路径和搜索引擎收录，防不了群里的人把链接转出去。这里的「安全」指的是不暴露控制面（面板地址、Token、其他群内容），不是保密。

隧道本身要保活——插件只能探「当下通不通」，探不到「十分钟后还通不通」。隧道挂了但 5 分钟缓存还没过期时，那一次入群仍会发链接。

## 图鉴里都有什么、怎么排除

- **一个插件 = 一个分区**，分区名取自插件的显示名；没有显示名的可以在「插件显示名称」里配一个中文名
- **指令权限按 AstrBot 真实的权限过滤器识别**（`PermissionTypeFilter`）
- 一个插件里**混着管理员指令和公开指令时，公开的那些会正常列出来**，管理员的那些剥掉
  - 例：某插件有 `/签到`（所有人可用）、`/天气`（所有人可用）、`/重置`（管理员）→ 图鉴里只列前两条，这个插件照样显示
- 一个插件**只有**管理员指令时，整个插件不出现在图鉴里
- **网页永远不显示管理员指令**，且不受「显示管理员指令」那个开关影响——那是公网页面，不能把 `/图鉴重置`、`/图鉴链接` 这种入口贴出去
- 框架本体（`astrbot`）和内置提醒不列
- 本插件自己的指令**会**列出来（就是上表那几条公开指令），管理员那几条照剥
- 想知道「到底扫到了什么、漏了什么」，发 `/图鉴预览`：下半段会把识别结果、框架本体不列的、被黑名单挡掉的都摊开写

## 触发规则

- 只认**机器人自己被拉进群**（通知里的 `user_id` 等于自己的 `self_id`），群里别人进群不触发
- 同一个群**只发一次**；插件重启、热重载都不会重复发
- 被踢之后重新拉进群，会**再发一次**
- 双保险：主判据是 OneBot 的群成员增加通知，兜底是「收到一个没见过的群号」。有些 OneBot 实现不会给机器人自己上报 `group_increase`，兜底就是救这个的场，`/图鉴入群检测` 可以单独关

> 已知限制：如果新群不在 AstrBot 的会话白名单里，框架的 `WhitelistCheckStage` 跑在唤醒阶段之前，会在插件看到之前就把事件丢掉，欢迎语发不出来。这不是本插件的问题，但要知道。

## 静默是干什么的

进群后的一段时间（默认 60 秒）内，**只掐掉 LLM 调用，指令照常响应**。

先摆正一个预期：**入群那一瞬间本来就不会调 LLM**——没人会 @ 一个刚进群的机器人。
AstrBot 只在「@ 了机器人 / 带唤醒词 / 私聊」时才走 LLM。所以静默的真正作用是：

> 进群后的 60 秒内，如果有人 @ 它，不响应。

避免的是「刚进群就被人 @ 着玩，连着触发好几轮」这种情况。

用 `on_waiting_llm_request` + `stop_event()` 实现（源码确认调用点是
`if await call_event_hook(...): return`）。指令不受影响，管理员随时能查状态。

只能管住自己的 bot，群里其他 bot 该刷屏还是刷屏。

静默和「入群时发欢迎」是两个独立开关：`/图鉴入群 静默开｜静默关`。

## 配置项

**图片相关**

- **图鉴标题 / 图鉴简介**：图片与网页共用的文字
- **卡片不透明度**（20～100）、**每行指令数**（1～4 栏）
- **显示 AstrBot 内置指令**、**显示管理员指令**（只管图片）、**自定义额外指令**、**插件显示名称**、**插件黑名单**

**网页相关**

- **启用欢迎页服务**：关掉就不再监听本地端口
- **欢迎页本地端口**：默认 41783，被占用会自动往后找且不落成连号
- **对外访问地址**：留空 = 不发链接，退回发图鉴
- **网页访问密钥**：留空自动生成；`/图鉴链接 换` 轮换
- **入群时发欢迎**、**入群欢迎语**（`{link}` 是链接占位符，默认不表明是机器人）、**进群静默秒数**、**入群检测方式**（`notice`/`unknown`/`both`/`off`）、**网页顶部使用规则**、**按群定制页面**

## 安装与升级

- 安装：插件市场搜索「指令图鉴」，或下载 zip 后在 Dashboard 上传安装。
- 升级：**先在面板卸载旧版（不要勾选「删除配置/删除数据」），再上传新版 zip**。所有自定义样式与群记录都存在 `data/plugin_data/help_dex/`，升级不会丢失。
- 依赖：Pillow 与 aiohttp（AstrBot 自带，无需额外安装）。

## 说明

- 内置字体为抖音美好体（Douyin Sans Bold，可免费商用）。网页用系统字体栈，不嵌字体，加载更快。
- Logo 白底去除基于亮度阈值（≥235 视为白底），建议上传白底或透明底图片。网页里的 Logo 会缩到 128px 高再内嵌。
- 上传背景图后，图面会自动叠加半透明蒙版保证文字可读。**网页不内嵌背景图**，一张 2MB 的图会让整页变重。
- 网页尊重系统的「减少动态效果」设置，开了就全部关掉动效。
