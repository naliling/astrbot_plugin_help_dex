# 指令图鉴（help_dex）

把机器人会的一切指令画成一张暗色科幻风的图鉴图片。背景图、Logo、字体颜色全部支持**用指令直接上传和修改**，改完立即生效，不用碰文件、不用重启。

## 指令

### 所有人可用

| 指令 | 说明 |
| --- | --- |
| `/帮助图鉴` | 生成指令图鉴图片（发 `指令图鉴` 也可以） |
| 只 @ 机器人 | 群里只 @ 它、不发任何文字，也会直接发图鉴 |
| `/图鉴预览` | 预览当前图鉴效果，并显示自定义状态 |
| `/图鉴帮助` | 查看本插件全部用法 |

### 管理员可用

| 指令 | 说明 |
| --- | --- |
| `/图鉴背景` + 图片 | 上传背景图（也支持发图片链接）；发 `/图鉴背景 重置` 恢复默认渐变 |
| `/图鉴logo` + 图片 | 上传 Logo，白底自动抠掉；发 `/图鉴logo 重置` 移除 |
| `/图鉴颜色 <部位> <颜色>` | 自定义配色，如 `/图鉴颜色 标题 #FF5733` |
| `/图鉴标题 <文字>` | 改图鉴大标题 |
| `/图鉴简介 <文字>` | 改标题下的简介 |
| `/图鉴重置` | 颜色、标题、背景、Logo 全部恢复默认 |

可自定义颜色的部位：`背景`（可两个颜色做渐变）、`标题`、`副标题`、`区块`、`指令`、`描述`、`强调`、`卡片`、`边框`、`页脚`。颜色格式 `#RRGGBB`，`卡片` 还支持 8 位带透明度 `#RRGGBBAA`。单独发 `/图鉴颜色` 可查看当前配色。默认是暗色科幻配色（深空底 + 蓝青点缀），不喜欢可以随时改。

## 配置项

- **图鉴标题 / 图鉴简介**：帮助图顶部的文字
- **卡片不透明度**：20～100，越低卡片越透明、背景越明显（想突出背景图就调低）
- **每行指令数**：1～4 栏，栏数越多图片越短（默认 3 栏网格排版）
- **显示 AstrBot 内置指令**：是否列出原生自带指令
- **显示管理员指令**：默认关闭，需要时再开
- **自定义额外指令**：正则/监听器形成的指令收集不到时手动补充，格式 `命令:描述`
- **插件显示名称**：给没有外显名的插件起中文名，格式 `插件名:显示名称`
- **插件黑名单**：不想出现在图鉴里的插件

## 安装与升级

- 安装：插件市场搜索「指令图鉴」，或下载 zip 后在 Dashboard 上传安装。
- 升级：**先在面板卸载旧版（不要勾选「删除配置/删除数据」），再上传新版 zip**。所有自定义样式（颜色、标题、背景图、Logo）都存在 `data/plugin_data/help_dex/`，升级不会丢失。
- 依赖：Pillow 与 aiohttp（AstrBot 自带，无需额外安装）。

## 说明

- 内置字体为抖音美好体（Douyin Sans Bold，可免费商用）。
- Logo 白底去除基于亮度阈值（≥235 视为白底），建议上传白底或透明底图片。
- 上传背景图后，图面会自动叠加半透明蒙版保证文字可读（暗色主题叠深色蒙版、浅色主题叠白色蒙版）；若想保留更浓的背景，可把「卡片」颜色设为带透明度的值（如 `#16223ACC`）。
